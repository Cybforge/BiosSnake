# Project Rules: 100% English Only in Code, UI & Documentation

- **Strict English-Only Policy**: All BIOS UI strings, Setup menus, UEFI/BIOS Shell texts, filesystem (`CybFS`) files, assembly source code (`bios.asm`, `src/base_bios.txt`), Python generator scripts (`gen_bios.py`), code comments (`; ...` and `# ...`), and project documentation (`README.md`) **MUST be written 100% in English**.
- **Never Mix German and English**: Never use German words (such as `Reiter`, `Zeile`, `Spalte`, `Speicher`, etc.) in any BIOS strings, UI labels, comments, or source files, even when the user prompts in German.
